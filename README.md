# Canal Familiar

Proyecto de canal automatizado de desafíos visuales originales para una audiencia familiar hispanohablante.

## Estado actual

Fase de validación editorial. Antes de automatizar la producción diaria se debe completar y validar:

- 1 video largo piloto.
- 3 Shorts originales.
- Revisión visual en teléfono y televisor.
- Revisión de retención, comprensión y respuesta de la audiencia.

## Principio del proyecto

La automatización ejecutará un producto editorial previamente diseñado; no reemplazará la selección humana ni convertirá el canal en contenido repetitivo producido en masa.
